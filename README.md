### [TAIquest](https://github.com/KevinMayan94/taiquest)
A practice app for the Spanish TAI civil-service IT exam: 6,746 real exam questions served as configurable tests and mock exams, with a review queue for failed questions and accuracy per subject.

I migrated it from a single static page (13 MB of JS data, progress in `localStorage`) to a full client–server app: a normalized 11-table schema, an idempotent import command, PHPUnit functional tests and CI on GitHub Actions.

`Angular` · `Symfony 7` · `Doctrine` · `MySQL` · `PHPUnit` · `Docker Compose` · `GitHub Actions`
